## 🔒 100% Secure & Hack-Proof 

We take your privacy seriously. This VPN is built with an iron-clad security architecture:
- **No API Keys**: We have completely eliminated hardcoded API keys. 
- **Zero Hackable Tokens**: There are no hidden backdoors or tokens that can be compromised.
- **Pure WireGuard Power**: Built directly on top of the state-of-the-art WireGuard protocol.
- **Secure Storage**: Any local configurations are protected using bank-grade local device keystores.

## ✨ The Ultimate Security Suite Features

This is not just a VPN. It is a full Network Intelligence & Privacy Suite:

- 🚀 **Lightning Fast VPN**: Experience the raw speed of the WireGuard protocol with a beautiful animated connect screen.
- 📡 **Cellular Tower Radar**: Track the nearest cell tower, monitor your mobile signal strength in precise dBm, and get alerts if the signal drops.
- 🌐 **IP & Network Intelligence**: Run a full scan on your connection to check your exact public IP, Location, ISP, and if your DNS is leaking.
- 📶 **Smart Wi-Fi Scanning**: Analyze your surroundings, check Wi-Fi security (WEP/WPA2/WPA3), and auto-connect to the VPN on untrusted networks.
- 🕵️ **Spy Camera Detector**: Scan your local network for hidden cameras, IoT devices, and unauthorized tracking hardware in hotels or Airbnbs.
- 📊 **Real-time Analytics**: Live upload and download speed charts visualizing your secure tunnel traffic.

## 🚀 Quick Start

### Step 1: Clone the Repository
```bash
git clone https://github.com/thisal-wtc/VPN-SECURITY.git
cd VPN-SECURITY
```

### Step 2: Install Dependencies
```bash
flutter pub get
```

### Step 3: Run the App
Launch the ultimate secure VPN experience on your physical device:
```bash
flutter run
```
